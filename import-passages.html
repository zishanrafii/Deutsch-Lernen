📥 Reading Passages — Bulk Import

এই page একবার ব্যবহারের জন্য — seed-data/reading-passages-{level}.json ফাইলগুলো (a1, a2, b1, b2, c1, c2 — ৬টা ফাইল, প্রতিটা একটা CEFR level-এর জন্য) থেকে সব passage পড়ে Firestore-এর reading_passages collection-এ লিখে দেয় (প্রতিটার Firestore doc id = তার slug, তাই দ্বিতীয়বার চালালেও duplicate হবে না, শুধু overwrite হবে)।

⚠️ admin হিসেবে login করা অবস্থায় এই page চালান (Firestore rule-এ যদি write-access শুধু admin-দের জন্য রাখা থাকে)। কাজ শেষ হলে এই file আর deploy করার দরকার নেই।
